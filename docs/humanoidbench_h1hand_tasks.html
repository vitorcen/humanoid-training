HumanoidBench h1hand-* 任务详情

Comprehensive survey of all 31 HumanoidBench tasks under the h1hand (76-DoF, dexterous-hand) variant
定位 / Scope：HumanoidBench (HB) 给 Unitree H1 + Shadow-Hand-like dexterous hands 提供 31 个 gym task。本文按"locomotion / manipulation / whole-body"分类，列出 success_bar、reach skill 支持、本项目 DR.Q 自训通关 ckpt 覆盖、剩余 manipulation gap。

HB has 31 gym tasks for H1Hand (76-DoF body + dex hands). This doc categorizes by task family, lists success bars, reach-skill availability, our DR.Q passing ckpts, and the remaining manipulation gap.

0. TL;DR

  • 31 个 task，每个 task 自动适配 6 个 robot 变体（h1 · h1hand · h1simplehand · h1strong · h1touch · g1） = 共注册 ~186 gym IDs
  • h1hand DoF：76（19 body + 2×26 + 5 shadow-hand-style；action 实际 61D normalized）
  • 分类：
    • locomotion 9 walk · run · stand · crawl · pole · hurdle · stair · slide · sit (×2) · balance (×2)
    • manipulation 10 reach · push · package · truck · bookshelf (×2) · door · maze（有 reach skill 16 个） + cube · cabinet · window · spoon · insert (×2) · basketball · kitchen · highbar（无 reach skill 9 个）
    • whole-body 3 highbar · powerlift · room
  • 本项目状态：
    • ✅ DR.Q 自训通关 9/9 H1 locomotion（已发 wsagi/HumanoidBench-DrQ）
    • 🟡 H1 manipulation gap 7 个待攻：cube · kitchen · cabinet · window · spoon · insert · highbar — 走 GR00T 路线（见 docs/groot_six_decisions.html）
  • vs Isaac Lab G1：HB 是 MuJoCo 原生 + 完整 task scene + dense reward + RL training-ready；缺点是用 H1（≠ G1），renderer 简单

3. Gym ID 命名规则

{robot}-{task}-v0

# 例子
h1hand-walk-v0           # H1Hand 走路
h1hand-cube-v0           # H1Hand 双手 cube reorientation
h1hand-cabinet-v0        # H1Hand 开柜门
g1-walk-v0               # G1 走路（auto blocked_hands=True for DR.Q）

# Robot 选项：h1 | h1hand | h1simplehand | h1strong | h1touch | g1
# Task 选项 (31)：见 §1

注：__init__.py patched 2026-05-26 — G1 任务自动启用 blocked_hands=True 屏蔽 14 维手指，避免 DR.Q 的 σ=0.2 noise 污染 encoder dynamics（见 docs/g1_training_strategies.html）。

4. 环境接口 / Env API

import gymnasium as gym
import humanoid_bench  # registers all 186 IDs

env = gym.make("h1hand-window-v0", render_mode="rgb_array")
obs, info = env.reset(seed=0)
# obs.shape ≈ (151,) for h1hand
# env.action_space.shape = (61,)

action = env.action_space.sample()
obs, reward, terminated, truncated, info = env.step(action)
# info["success"]    — bool, 是否达成 task goal
# info["success_subtasks"] — only for cabinet / kitchen, list of subtask flags

# render
img = env.render()   # → (256, 256, 3) uint8

关键 env kwargs

kwarg默认说明
render_mode"rgb_array"可选 "human"（MuJoCo viewer）/ "depth_array"
width / height256render 分辨率
randomness0.01物体初态随机化
policy_pathNone低层 reach skill ckpt 路径（仅 reach-skill task 用）
blocked_handsFalse（G1: True）屏蔽手指自由度 → action_dim 减
small_obsFalse用 reduced obs（subset of full state）

8. Manipulation gap 攻关路线（本项目当前焦点）

策略（基于 docs/groot_six_decisions.html 的 6 决策对齐）：
  1. D5：第一 task = h1hand-window-v0（base 锁站姿 + 单手 EEF 最干净）
  2. D1：Demo 来源 = scripted reach skill (b) + FSM (a)
    给 cube/cabinet/window/spoon/insert 补 htarget_low/high bbox（patches/），用 reach skill 辅助 FSM 生成 30-50 ep demos
  3. D2：Action mask
    61D HB action 中只让 GR00T 学 28D arms+hands；剩 33D legs + waist 锁 standing preset
  4. D3：DEX3-1 5指（HB 用 Shadow-style 26-DoF/手）
    初版用 3-state preset（open/half/close），后期再放开
  5. D4：实时预览 = MuJoCo passive viewer + GR00T PolicyServer ZMQ
  6. D6：Eval = N=10 ep × 3 seeds，info["success"] + 失败阶段分布

10. 复现命令 / Quick reproduce

# 1. clone with submodule
git clone --recursive https://github.com/vitorcen/humanoid-training
cd humanoid-training && bash patches/apply.sh

# 2. conda env

pip install -e dependencies/humanoid-bench

# 3. 列出所有 h1hand task IDs

    print([e for e in gym.envs.registry if e.startswith('h1hand-')])"

python scripts/native_viewer.py --env h1hand-window-v0 --action random
