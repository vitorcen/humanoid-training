定位 / Scope：本次扫了 HF datasets API 与 LeRobot doc，整理出在 LeRobot / GR00T / RoboCasa / ManiSkill 几个生态里**公开可下载**的 Unitree G1 数据集（≥ 10 downloads，或者 LeRobot 官方 doc 推荐）。配套 Datasets.ipynb 提供一键 sim replay 预览。

0. TL;DR

  • 3 类来源：① RoboCasa 仿真合成（最大规模，1k+ episodes）② Homunculus 外骨骼 / VR teleop（LeRobot 主流来源）③ ManiSkill 仿真（少量但 well-documented）
  • 4 种 G1 变体：G1_29DoF（全 29 自由度）· G1_23DoF（无手）· G1_Dex3（3 指 trihand）· G1_Inspire-FTP（5 指 Inspire 灵巧手）
  • 实时预览有 2 条路径：
    • A 路径 · sim replay lerobot-replay --robot.type=unitree_g1 --robot.is_simulation=true --dataset.repo_id=X — 在 G1 MuJoCo sim 里回放 dataset action
    • B 路径 · Rerun viewer lerobot-dataset-viz --repo-id X — 不启 sim，浏览 video + state trajectory
  • 5 个代表性数据集（按"分类多样性 + 下载量 + schema 兼容性"挑出，已配置在 Datasets.ipynb 一键按钮）

2. 实时预览技术路径

路径 A：sim replay（推荐）

把 dataset 里的 action 序列**直接驱动 G1 MuJoCo sim**，看机器人在 sim 里"回放"录好的动作。这是 LeRobot 官方 lerobot-replay 命令做的事。

lerobot-replay \
    --robot.type=unitree_g1 \
    --robot.is_simulation=true \
    --robot.cameras='{"global_view":{"type":"zmq","server_address":"localhost",
                       "port":5555,"camera_name":"head_camera",
                       "width":640,"height":480,"fps":30,"warmup_s":5}}' \
    --dataset.repo_id=nepyope/unitree_box_move_blue_full \
    --dataset.episode=0

会自动启 G1 MuJoCo viewer（资产从 lerobot/unitree-g1-mujoco 拉），然后逐帧把 dataset action 喂给 sim。前提：dataset 的 action schema 与 LeRobot unitree_g1 robot 期望的接口对齐。

Schema 兼容性矩阵 / Schema compat：
  • ✅ nepyope/*（Homunculus teleop）— LeRobot doc 官方 example，最稳
  • ✅ Breno-de-Angelo/*（dex3 teleop）— 已标 LeRobot tag
  • ⚠️ jnsungp/*（RoboCasa）— 是 RoboCasa Isaac Sim 风格，action 可能需要 transform 才能给 LeRobot G1 sim
  • ❌ johnMinelli/ManiSkill_*（ManiSkill）— ManiSkill action schema 与 LeRobot 不兼容，建议走 B 路径

路径 B：Rerun viewer（兜底）

不启动 sim，用 Rerun 浏览数据集 video + state trajectory + action 曲线。任何 LeRobot 格式 dataset 都能开，schema 不兼容也能看。

lerobot-dataset-viz \
    --repo-id jnsungp/unitree-g1-robocasa-pick-apple-bowl-contact-1k \
    --episode-index 0

会弹 Rerun GUI（X11），左侧 timeline，右侧 3-pane（视频 / state plot / action plot）。在 sim replay 失败时用这个排查 — 至少能看清楚数据长什么样。

5. 一键预览 — Datasets.ipynb 设计

配套的 Datasets.ipynb notebook 提供：

  • §1 环境检查：自动检测 lerobot-replay / lerobot-dataset-viz CLI 是否可用；缺失时给出 sister repo 安装提示
  • §2 5 按钮一键预览：上表 5 个代表性 dataset，每个一个按钮；点击后：
    1. HF snapshot_download（自动缓存到 ~/.cache/huggingface）
    2. 优先尝试 A 路径（sim replay）；如果 schema 不兼容，自动 fallback 到 B 路径（Rerun viewer）
    3. subprocess.Popen 启动外部进程，输出写到 .viewer_logs/
  • §3 完整对照表：所有候选 dataset 的紧凑表格 + 直接拉取 cell
  • §4 数据集 inline 浏览（不启 sim，最快）：用 LeRobotDataset API 直接 inline 显示第 N episode 的视频 + state plot — 当 GUI 不能用时的极简兜底
