Isaac Lab G1 Locomanipulation 任务详情

A focused survey of Isaac Lab's three Unitree G1 manipulation / loco-manipulation tasks
定位 / Scope：Isaac Lab 在 G1 上有 3 个 manipulation 类预定义 gym task（不含 locomotion 4 个 velocity tasks）。本文逐一拆解：scene 内容、action / obs schema、数据生成机制、与 LeRobot G1 sim 的差异，以及对本项目（humanoid-training）"看 G1 真实抓水壶"目标的适用性。

Isaac Lab provides 3 predefined G1 manipulation tasks (separate from 4 locomotion velocity tasks). This doc breaks down each one's scene, action/obs schema, data-generation pipeline, and applicability to our "see G1 actually pick a kettle" goal.

0. TL;DR

  • 3 个 task ID：Isaac-PickPlace-Locomanipulation-G1-Abs-v0 · Isaac-PickPlace-FixedBaseUpperBodyIK-G1-Abs-v0 · Isaac-PickPlace-G1-InspireFTP-Abs-v0
  • 真实任务 scene：PackingTable（桌子）+ steering_wheel.usd（默认 object — 可换 kettle.usd 等）+ DomeLight + GroundPlane — 这是 LeRobot G1 sim **没有**的
  • Data 来源：OpenXR + Manus Vive teleop 录少量 seed demos → Isaac Lab Mimic SDG（synthetic data generation）放大到 1000 trial
  • Policy 范式：robomimic BC-RNN（low-dim 或 image），不是 RL
  • 对本项目的最大价值：完整 task scene + 物理验证 + Mimic 数据放大。能用同一套 G1 USD asset 验 GR00T policy 输出是否真能完成 task（不是 lerobot-replay 的"空气抓"）
  • 代价：Isaac Sim 启动慢（~30s），需 NVIDIA Omniverse + USD 资产；不在 conda env 里 light-weight

3. Action / Observation Schema

Action — 上半身 IK + 下半身 Agile RL controller

upper_body_ikG1_UPPER_BODY_IK_ACTION_CFG（Pink IK）2× EEF 6D + 双 TriHand → IK 出 14 arm + N hand用 pinocchio Pink IK solver，输入 EEF 目标，输出关节角

关键洞察：Isaac Lab 不让 policy 直接控制 49+ 关节，而是**分层** — 上半身只学 EEF 目标（policy 学），下半身用 pretrained agile locomotion policy 自动平衡。这是 NVIDIA 在 N1 白皮书里的标准做法。

流程图 / Pipeline

SubTask 配置（轨迹切分）

Mimic 把一个完整 pick-place trajectory 切成多个 subtask，按 binary indicator (datagen_info["idle_right"] 等) 标记切分点。这允许：

  • 不同 episode 的 subtask 段可以**互换** — 比如 "走到桌前"段 + "右手抓"段 + "放下"段 任意组合 → 1000 unique trajectories from ~10 seed
  • 每个 subtask 单独 reset 物体位置 → 增加 task variance
SubTaskConfig(
    object_ref="object",                            # 关联场景里的 RigidObject
    subtask_term_signal="idle_right",               # binary indicator 标识 subtask 结束
    first_subtask_start_offset_range=(0, 0),
    subtask_term_offset_range=(0, 0),
    ...
)

7. 对 humanoid-training 项目的应用

最佳用法：在 humanoid-training 的 6 决策路线下，Isaac Lab G1 task 可作为：
  1. 验证 GR00T finetune policy 输出的有效性
    Day 5+ 用 GR00T (NEW_EMBODIMENT) finetune 后，把 policy 接到 Isaac-PickPlace-FixedBaseUpperBodyIK-G1-Abs-v0 跑 N=10 rollout，看 task success rate（替代 lerobot replay 的"空气抓"）
  2. 参考 Mimic SDG 思路给 HumanoidBench 写数据 pipeline
    HB 没有 Mimic，但可借鉴：seed demos （手写 scripted FSM）→ subtask 切分 → 重组生成新轨迹（自己写一套类似 SDG 的）
  3. 对比 reward / termination 设计
    Isaac Lab 的 pick-place reward 是 HB manipulation gap task 缺的（很多 HB task 没 dense reward），可参考

不要用在

  • ❌ 当作主要 sim 平台（启动慢、资产重，与 D4 决策"用 MuJoCo passive viewer"冲突）
  • ❌ 用 H1（Isaac Lab G1 task 不能直接迁移；H1 task 是另一套）
  • ❌ 做 locomotion（locomotion 用 RL 路线 = DR.Q，不走 BC）

8. 已知限制 / Caveats

  1. USD asset 依赖 Isaac Nucleus：{ISAAC_NUCLEUS_DIR} 需要 Isaac Sim 启动后通过 Omniverse 拉取，第一次启动慢
  2. BC-RNN 不是 SOTA：robomimic 是 2021 时代框架，现在 GR00T / pi0.5 / SmolVLA 远更强，但 Isaac Lab 默认配的是 BC-RNN
  3. Default object 是方向盘 steering_wheel：不是 kettle。要 kettle 自己换 USD
  4. 没有公开预训练 ckpt：Isaac Lab 不像 lerobot 那样在 HF 发 G1 ckpt，需自训
  5. 奖励信号：subtask_term_signal 需要在 mdp 里手动定义，object-specific

10. 复现命令 / Quick reproduce

# 1. 启 Isaac Lab env
cd ~/work/isaaclab-experience && conda activate isaaclab

# 2. 查看 gym ID 是否注册成功
python -c "import gymnasium as gym, isaaclab_tasks; \
    print([e for e in gym.envs.registry if 'G1' in e])"

# 3. 用随机 action 跑一个 episode（验环境通）
./isaaclab.sh -p scripts/environments/random_agent.py \
    --task Isaac-PickPlace-FixedBaseUpperBodyIK-G1-Abs-v0 --num_envs 1

# 4. VR teleop 收 seed demos (需 OpenXR + Manus Vive 硬件)
./isaaclab.sh -p scripts/imitation_learning/teleop_se3_agent.py \
    --task Isaac-PickPlace-Locomanipulation-G1-Abs-v0 \
    --device openxr --num_demos 10

# 5. Mimic SDG 放大到 1000 demos
./isaaclab.sh -p scripts/tools/mimic_generate.py \
    --task Isaac-PickPlace-Locomanipulation-G1-Abs-v0 \
    --source seed_demos.hdf5 --output gen_demos.hdf5

# 6. BC 训练
./isaaclab.sh -p scripts/workflows/robomimic/train.py \
    --task Isaac-PickPlace-Locomanipulation-G1-Abs-v0 \
    --dataset gen_demos.hdf5 --algo bc
